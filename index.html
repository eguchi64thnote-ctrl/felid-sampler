Playback first chooses an active group by its WEIGHT, then an enabled material inside that group. Uploaded files remain in this browser session; reloading the page clears them.
Rhythm engine / source cuts
RHYTHMIC DIVISION / TUPLETS — subdivisions per quarter-note beat
CURRENT GROOVE: AUTO / waiting
CURRENT DIVISION: STRAIGHT / 4 per beat
CURRENT GROOVE MIX manually sets the balance between the two displayed groove grammars; GROOVE DRIFT controls how readily the groove identities change. Tuplet modes divide each quarter-note beat into 3 / 5 / 7 / 9 / 11 equal pulses; AUTO can change the division as the groove evolves. Rhythmic cuts are sliced from whichever FeLid material groups are currently active. Magic Hour and In can be used separately or mixed together. The optional 808 layer is synthesized in-browser — no external drum samples are added.
Mixer / rhythm definition
MASTER + SOURCE CUTSsample-derived rhythm
808 SYNTH LAYERgenerated tone / noise
808 MIX at 0% = pure source cuts. Raise it slightly to reveal the pulse without replacing the source character. BASS / SUB only appears in gaps where KICK / PERC do not fire. ATTACK and RELEASE move from short, funky low notes to longer hip-hop / trap-like sub tones; TONE adds upper definition, and GAP FILL controls how often those empty spaces are used.
Random movement
RANDOM WALK ON continuously moves every sound parameter at the same time — ENGINE / SOUND / SILENCE, RHYTHM ENGINE, MIXER, and 808 SYNTH LAYER. Each control has its own independent direction and speed and keeps drifting inside its own RANDOM RANGE. Press WALK beside any parameter to switch it to HOLD; that parameter freezes immediately while every other unlocked parameter keeps moving. WALK SPEED controls continuous movement.
RANDOM WALK continuously moves every sound parameter — ambient/silence, rhythm, mixer, and 808 — without stopping. Every sound parameter has its own editable RANDOM RANGE (MIN / MAX) and its own WALK/HOLD switch, so each control can wander forever inside a deliberately bounded musical territory or be frozen independently. TEMPO reaches 296 BPM and RHYTHM SLICE LENGTH reaches 6 seconds. RHYTHMIC DIVISION adds straight 16ths plus 3 / 5 / 7 / 9 / 11 tuplets, with an AUTO mode that can change division as the groove evolves. The mixer separates source-derived KICK / SNARE / HAT / PERC roles, with an optional synthesized 808 layer.
